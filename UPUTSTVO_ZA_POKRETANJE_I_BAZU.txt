UPUTSTVO ZA POKRETANJE PROJEKTA
==============================

1. Baza podataka
----------------

Pokrenuti MongoDB i MongoDB Compass, a zatim se povezati na:

mongodb://127.0.0.1:27017

Napraviti bazu pod nazivom:

printing_house

U njoj napraviti sledeće kolekcije i u svaku uvesti odgovarajući JSON fajl iz
foldera `baza` opcijom Add Data -> Import JSON or CSV file:

- users       <- baza/users.json
- categories  <- baza/categories.json
- products    <- baza/products.json
- orders      <- baza/orders.json
- tenders     <- baza/tenders.json

JSON fajlovi su nizovi MongoDB Extended JSON dokumenata. Kolekcije treba da budu
prazne pre uvoza da ne bi došlo do ponavljanja istih `_id` vrednosti. Slike
proizvoda su već ugrađene u products.json kao Base64 podaci.

2. Backend
----------

Otvoriti terminal u folderu `backend` i pokrenuti:

npm install
npm run build
npm start

Backend se povezuje na bazu:

mongodb://127.0.0.1:27017/printing_house

i pokreće se na:

http://localhost:4000

3. Frontend
-----------

Otvoriti drugi terminal u folderu `frontend` i pokrenuti:

npm install
npm start

Frontend se pokreće na:

http://localhost:4200

Globalna instalacija Angular CLI-ja nije obavezna jer se lokalna verzija
instalira iz package.json fajla.
